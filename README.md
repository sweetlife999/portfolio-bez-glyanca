# Без глянца — portfolio

Public portfolio for marketplace and online-product design: cards, descriptions, decks and landings.
Three concept projects on Pexels photos. No client data, no AI images.

## Structure
- `index.html`, `styles.css` — static one-page site.
- `assets/v2/cards/` — 10 approved cards.
- `assets/v2/portfolio.pdf` — 13-page PDF.
- `assets/v2/cover.png`, `qr.png`.
- `assets/v2/fonts/` — Lora and Golos Text with OFL licenses in `assets/v2/licenses/`.
